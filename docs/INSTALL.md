# Installation and testing

## Chrome

1. Visit `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select the `MuseAi-Sidebar-Extension` folder.
5. Pin the extension from the puzzle-piece menu.
6. Click the Muse AI Sidebar toolbar icon. The side panel should open.
7. Click **Open Muse AI** and confirm a new tab opens at `https://muse.ai/`.

## Microsoft Edge

1. Visit `edge://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select the `MuseAi-Sidebar-Extension` folder.
5. Pin the extension, click its toolbar icon, and test the side panel.

## Test checklist

- The extension loads without manifest errors.
- Clicking the toolbar icon opens the side panel.
- The animated background is visible and stays dark and readable.
- The **Open Muse AI** button opens Muse AI in a new tab.
- The refresh button updates the local connection status.
- With reduced motion enabled in the OS/browser, animations are minimized.
