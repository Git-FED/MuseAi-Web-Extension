GET STARTED

Install in
two minutes.

Chrome

  1. Open chrome://extensions.
  2. Turn on Developer mode.
  3. Select Load unpacked.
  4. Choose the unzipped MuseAi-Sidebar-Extension folder.
  5. Pin the extension and click its toolbar icon.

Microsoft Edge

  1. Open edge://extensions.
  2. Turn on Developer mode.
  3. Select Load unpacked.
  4. Choose the unzipped project folder.
  5. Pin the extension and test the side panel.

Deploy this site

This folder is static and can be served from GitHub Pages or Cloudflare Pages. Use the site directory as the Pages output directory. There is no build command.
