WHAT’S INSIDE

Thoughtful
little details.

Animated atmosphere

Layered light streaks, subtle grid glow, texture, responsive tilt cards, signal pulses, and a reduced-motion fallback create a premium dark visual system without using orbital graphics.

Chromium side panel

The extension uses Manifest V3 and the Chromium sidePanel API for Chrome and Edge. There is no backend, no build command, no remote code, and no analytics.

One clear action

The panel keeps the experience simple: click the toolbar icon, then choose Open Muse AI. The service opens in a new tab so authentication and cross-origin restrictions stay out of the extension shell.
